# Changelog

## 1.1 — 2026-10-01

### Active Break

A break reminder that brings a rain shower to the desktop without locking you out. On a schedule you choose, rain fades in over whatever you're doing. Clicks and typing pass straight through — a nudge to pause, minus the wet.

- Settings → Rain Break: turn it on, set the interval, and end it with the hotkey.
- Rain and sound can build gradually from a faint start up to full strength.
- Turn off "Allow desktop interaction" for the classic blur-and-lock break instead (dismiss with ESC or the hotkey).
- Once a gradual break reaches full rain, lightning switches to storm timing.

### Active Rain

Click-through rain you can leave on while you work. Switch from the tray **Mode** menu or Settings → Hotkey.

- Opacity, haze removal, brightness, and tint (white, cool blue, soft gray, or a custom color).
- Separate rain volume, fade in and out, and optional resume when RainDelay starts.
- Hidden from screen sharing and recording.
- Pauses on a monitor when a full-screen app is in front.
- Frame keying runs off the UI thread so the hotkey and tray stay responsive.

### Also in this release

- Optional lightning flashes in screensaver and Active modes.
